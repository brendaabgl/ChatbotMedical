Cara menjalankan
----------------
1. pip install streamlit nltk scikit-learn pandas numpy deep-translator
   (opsional: pip install sentence-transformers  → lalu set ENABLE_SBERT = True)
2. Letakkan `medquad.csv` di folder yang sama dengan file ini
   (atau unggah lewat halaman web saat file belum ditemukan).
3. streamlit run app.py
